#+title: swh.el
#+options: toc:nil num:nil

Emacs client for [[https://www.softwareheritage.org][Software Heritage]] (SWH): archive your code, cite it
with a [[https://www.swhid.org][SWHID]], see where the files are already archived.

* Commands

- =swh= :: a menu of the commands below
- =swh-status= :: is the repo archived?
- =swh-visits= :: when was it last visited by SWH?
- =swh-save= :: save your repository now to SWH
- =swh-swhid-copy= :: copy the SWHID of the current directory/file/region
- =swh-swhid-copy-archived= :: copy the SWHID of the version the SWH
  archive holds
- =swh-swhid-copy-link= :: copy the link to it in the SWH archive
- =swh-swhid-open= :: open it in the SWH archive
- =swh-cite= :: show a BibTeX entry citing the code
- =swh-scan= :: show the repository's tracked files as a tree
- =swh-provenance= :: tell where the archive found the file's content,
  or the file or directory at point in Dired
- =swh-mode= :: show in mode line if the file/directory is archived
- =swh-refresh= :: forget what may have changed in the SWH archive

With =C-u=, or where there is no public origin, =swh-status=, =swh-visits=,
=swh-save= and =swh-cite= ask for the URL of a public repository instead.

By default, =swh-swhid-without-context= is nil so =SWHID= commands provide
their context. You can negate this option with C-u on those commands
or toggling the =-w= switch in the transient menu after =M-x swh RET=.

* Install

swh.el requires Emacs >=30.1 and =git=. You can install it with
=package-vc= and, as a suggestion, bind =C-c s= to copy a SWHID:

#+begin_src emacs-lisp
(use-package swh
  :vc (:url "https://github.com/bzg/swh.el")
  :bind ("C-c s" . swh))
#+end_src

Interactively:

: M-x package-vc-install RET https://github.com/bzg/swh.el RET

* Token or not token

Without a token, the archive allows 120 requests per hour. With a
token [[https://archive.softwareheritage.org/api/#authentication][from your archive account]], 1200 requests per hour. Set the
environment variable =SWH_API_TOKEN= (which swhd reads too), or add a
line in =~/.authinfo.gpg=:

: machine archive.softwareheritage.org password <token>

Optionally, you can also run the local [[https://github.com/bzg/swhd][swhd]] daemon: it caches SWHIDs
and provenances, and swh.el uses this cache. The =*swh scan*= header
will tell which way was used.

You can install swhd with [[https://github.com/babashka/bbin][bbin]]:

#+begin_src shell
bbin install io.github.bzg/swhd
#+end_src

* Customization

- =swh-daemon-url=: the daemon URL (default =http://127.0.0.1:8642=);
  swh.el goes through the daemon when it answers there, else talks to
  the archive's Web API itself.
- =swh-archive-url=: the archive's web root, where SWHIDs resolve and
  whose Web API is used.
- =swh-org-store-link=: whether =org-store-link= stores =swh:= links (=nil=, =t=
  or =ask=).
- =swh-mode-lighters=: the mode-line lighters of =swh-mode=.
